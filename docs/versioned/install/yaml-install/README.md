# YAML-based installation

You can install the Serving component, Eventing component, or both on your cluster
by applying YAML files.

Use this route when you want to apply and manage release manifests directly. For the responsibilities and alternatives, read [Choosing an installation method](../installation-methods.md). Before starting, check [installation requirements](../requirements.md).

Choose the component you need; neither guide requires installing the other component first.

- [Install Knative Serving with YAML](serving/install-serving-with-yaml.md)
