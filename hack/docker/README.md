# Development notes for working with MkDocs

Run `./hack/docker/run.sh` from the repository root for a live preview at
<http://127.0.0.1:8000/docs/>. Pass a host port as the first argument, for example
`./hack/docker/run.sh 8001`. An optional second argument selects a different image.

See the [local preview guide](../../contribute-to-docs/getting-started/previewing-docs-locally.md#alternative-docker)
for setup and the distinction between a local preview and a full release build.
